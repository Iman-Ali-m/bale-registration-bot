# Bale Registration Bot 🤖

An async Python bot for the **Bale** messenger with photo albums, inline keyboards, and user registration.

## ✨ Features

- ✅ Step-by-step registration (name, phone, education, field)
- ✅ Encrypted phone numbers with Fernet
- ✅ Photo albums (media groups)
- ✅ Inline keyboards (2 buttons per row)
- ✅ SQLite with WAL mode (aiosqlite)
- ✅ Rate limiting & DoS protection
- ✅ Async (aiohttp) — supports 100+ users
- ✅ Auto backup

## 🚀 Quick Start

```bash
pip install -r bale_requirements.txt
python bale_bot.py
